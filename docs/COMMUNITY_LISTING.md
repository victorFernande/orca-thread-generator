# Orca Thread Studio — community listing draft

Orca Thread Studio is an offline parametric generator for OrcaSlicer 2.5.1+: containers with screw lids, bottle-cap experiments, hose/vacuum adapters, bolts, nuts and hand knobs. It offers English/Portuguese controls, grey/teal light and dark themes, a full studio tab and a compact dock, plus STL/3MF export and direct Plater import requests.

A NumPy mesh engine generates connected watertight surfaces. The WebGL2 viewport shows those same triangles. A moving 2D engagement loupe, Higbee starts, multiple thread starts, configurable clearances and three physically marked test rings help calibrate printable fits.

Bottle profiles are experimental. PCO-1881 and Mason 70 use documented simplified envelopes; Mason 86 requires user measurements. No certified hardware tolerance, pressure rating, liquid-tightness or food-contact suitability is promised. Physical test prints remain necessary.

Português: gerador local de potes e tampas rosqueadas, adaptadores de mangueira, parafusos, porcas e manípulos, com prévia 3D, lupa de flancos e calibradores de encaixe. Instalação por arquivo Python único ou pacote wheel. Código MIT com testes de topologia, encaixe das malhas e integração.

Version 1.1.0 passed 68 local tests. A Windows session in OrcaSlicer 2.5.1 confirmed the page before the final theme adapters, generation, 3MF export, WM_COPYDATA delivery and the container base/lid visibly loaded on the Plater. Final dock/theme checks and native macOS/Linux integration remain pending; no slicing or physical print/fit test was performed. Open a 3MF as a project or use an empty plate; arrange objects when importing into an occupied project. See the [validation record](VALIDATION.md).
